# 安装与配置

## 一、装哪个版本

| 你的情况 | 用哪个 |
| --- | --- |
| 只想用，不打算改代码 | `xiaoman-pet-1.0.0-setup.exe`（安装版）或 `xiaoman-pet-1.0.0-portable.exe`（免安装） |
| 想改代码、加自己的模型 | 源码方式跑（见下一节） |

**系统要求**：Windows 10 1809 或更高 / Windows 11，64 位。语音合成用的是系统自带的 SAPI，中文音色（Microsoft Huihui Desktop）在中文版 Windows 上都已预装。语音识别与面部识别是可选的，用到时再装。

### 安装版和免安装版的区别

- 安装版默认装到 `%LOCALAPPDATA%\Programs\小满桌宠`，**可以自选目录**，带开始菜单和桌面快捷方式；卸载时**不会**删你的数据目录。
- 免安装版是一个单独 exe，双击就跑，适合放 U 盘。它每次都会解压到临时目录，启动比安装版慢一点。

两个版本的数据都放在 `%APPDATA%\小满桌宠\`：

```
%APPDATA%\小满桌宠\
  data\
    config.json          所有设置（含 API Key，明文，只在本机）
    memory\
      conversation.jsonl  聊天记录（每条带当轮情绪快照）
      longterm.jsonl      长期记忆（可编辑、可遗忘）
      summaries.jsonl     相处摘要
      emotion.jsonl       情绪时间线（网页端那条曲线就读它）
      state.json          当前心情 / 亲密度 / 精力
    logs\pet.log         运行日志
    tmp\                 语音识别的临时 wav
  models\
    whisper\             whisper.cpp 二进制与 ggml 权重
    mediapipe\           face_landmarker.task
```

想搬家或者备份，把整个 `%APPDATA%\小满桌宠\` 拷走即可。

## 二、从源码跑（开发模式）

```powershell
node -v          # 需要 22.15 或更新，脚本里用了 --use-system-ca
npm install      # 约 400 个包，第一次要十几分钟
npm run setup    # 拉 Live2D 模型 + 前端运行时（约 5 MB）
npm start        # 或 npm run dev（多打一点日志）
```

开发模式的数据目录是项目里的 `runtime\`，不碰 `%APPDATA%`：

```
runtime\
  data\    与打包版的 data\ 结构相同
  models\  与打包版的 models\ 结构相同
```

### 关于 `--use-system-ca`

有些机器上装了 TLS 中间证书，Node 自带的根证书列表不认 GitHub，会报：

```
UNABLE_TO_VERIFY_LEAF_SIGNATURE
```

npm 脚本里已经统一带上了 `--use-system-ca`（改用 Windows 系统证书库）。如果你手动敲命令，也要加上：

```powershell
node --use-system-ca scripts/fetch-live2d.mjs
```

应用本体不走这条路：下载统一走 Electron 的 `net.fetch`，天然使用系统证书与代理。

### 环境变量

| 变量 | 作用 |
| --- | --- |
| `PET_LOG_LEVEL` | `debug` / `info` / `warn` / `error`，默认 `info` |
| `PET_MODEL_DIR` | 覆盖模型目录（开发期默认 `runtime\models`） |
| `PET_WHISPER_MODEL` | `npm run fetch:runtime` 下载哪个规格，默认 `base` |
| `PET_LIVE2D_MODEL` | `npm run fetch:live2d` 拉哪个示例模型，默认 `Haru` |

### 可选：提前装语音组件

```powershell
npm run fetch:runtime
```

会下载 whisper.cpp 二进制（约 9 MB）、ggml 语音模型（`base` 约 142 MB）和 MediaPipe 面部模型（约 3.7 MB）。**这一步不做也能用**，管理页里点按钮是同一个下载流程。

下载源按「国内镜像 → 官方源」的顺序试，并且在超过 15 秒仍低于 80 KB/s 时会自动换下一个源；最后一个源不设速度门槛，所以慢网络最终也能下完。

### 打包

```powershell
npm run dist     # 生成安装版 + 免安装版到 dist\
npm run pack     # 只生成 dist\win-unpacked\ 目录，用于快速验证
npm run clean    # 清构建产物与临时文件（加 --data 才删 runtime\data）
```

## 三、跑起来之后要填的东西

### 3.1 对话模型

管理页 → **模型与人格**：

| 字段 | DeepSeek | 本地 Ollama |
| --- | --- | --- |
| 接口地址 | `https://api.deepseek.com` | `http://127.0.0.1:11434` |
| 模型名 | `deepseek-chat` | `qwen2.5:7b` 之类 |
| API Key | 你的 Key | 随便填，Ollama 不校验 |

接口地址会自动补 `/v1/chat/completions`（地址已经以 `/v1`、`/v2` 结尾时只补 `/chat/completions`）。填完点**测试连接**，通了再保存。

不填也能用：会走内置规则回复，消息后面带一行说明，不会假装自己很聪明。

### 3.2 语音

管理页 → **语音**：

1. 点**下载语音组件**，选规格（`base` 是推荐值）；
2. 识别语言默认中文，CPU 线程默认 4，机器好可以调到 6~8；
3. **开启语音监听**后，说「小满」就会唤醒它。

发声方式有三档：

- **Windows 系统语音**：默认。零安装，中文音色开箱可用。可以在下方下拉里指定音色。
- **本地 TTS 服务**：如果你跑着 GPT-SoVITS、Kokoro 之类的 OpenAI 兼容 `/v1/audio/speech` 服务，填地址和音色名即可。
- **关闭发声**：只看文字。

### 3.3 面部情绪（默认关闭）

管理页 → **情绪**，打开「表情」这一路，再在语音页下载 `face_landmarker.task`。打开后会用摄像头读你的表情来辅助判断情绪。

**画面不会离开渲染进程**：全部在本地 WASM/WebGL 里推理，不截图、不落盘、不联网。不想用了随时关掉，权重也能调成 0。

### 3.4 三路情绪权重

文字 / 声音 / 表情三路信号按权重加权融合，默认 `0.5 / 0.3 / 0.2`。用法建议：

- 主要打字聊天：把文字调到 0.7 以上；
- 主要用麦克风说话：把声音调高；
- 开了摄像头：表情给到 0.3 左右。
- 不用的那一路，权重给 0 就等于关掉。

## 四、配置项速查

配置文件是 `data\config.json`，管理页保存时**整体替换**（不是逐字段合并），所以直接改文件也行，改完重启应用。

### pet — 外观与行为

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `name` | `小满` | 它自称的名字，也是唤醒词 |
| `aliases` | `["小满","满满"]` | 叫这些名字它也会应 |
| `scale` | `1` | 窗口整体缩放，范围 0.35~2.5 |
| `opacity` | `1` | 窗口不透明度 |
| `alwaysOnTop` | `true` | 总在最前 |
| `clickThrough` | `false` | 打开后鼠标完全穿过它，只能靠托盘操作 |
| `silentMode` | `false` | 不主动搭话、不出声 |
| `lookAtMouse` | `true` | 视线跟随鼠标 |
| `idleWander` | `true` | 空闲时轻微晃动 |
| `model` | `Haru` | 用哪个 Live2D 模型 |
| `fit` | `height` | 适配方式：`height` 按高度铺满 / `contain` 完整显示 / `cover` 铺满并裁切 |
| `zoom` | `1` | 在适配结果上再缩放 |
| `offsetX` / `offsetY` | `0` | 水平 / 垂直偏移（像素） |
| `bubbleTimeoutMs` | `10000` | 气泡自动消失时间 |
| `bubbleMaxChars` | `220` | 气泡最多显示多少字 |
| `bubbleAreaHeight` | `132` | 顶部留给气泡的高度带，角色会站在这条带子下面 |

> `fit` 的默认值之所以是 `height`，是因为 Live2D 示例模型（Haru）的画布是 2400×4500 的竖长条，角色只占中间一块。按画布比例缩放会把头和脚裁掉，所以应用会先量出模型的真实内容范围再算缩放。

### llm — 对话模型

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `baseUrl` | `https://api.deepseek.com` | 接口地址 |
| `model` | `deepseek-chat` | 模型名 |
| `apiKey` | 空 | 密钥。**提交空字符串表示保持原值**，不会被清空 |
| `temperature` | `1.2` | 温度，桌宠场景偏高一点更有生气 |
| `maxTokens` | `700` | 单次回复上限 |
| `stream` | `true` | 流式输出 |
| `timeoutMs` | `60000` | 超时 |
| `fallback` | `true` | 调用失败时用内置规则兜底；关掉则直接报错 |

### memory — 记忆

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `recentTurns` | `12` | 多少轮最近对话直接进上下文 |
| `retrievalTopK` | `6` | 每轮最多召回几条长期记忆 |
| `minScore` | `0.1` | 召回的最低相关度 |
| `summarizeEveryTurns` | `10` | 每多少轮生成一次相处摘要 |
| `maxSummaryChars` | `1400` | 摘要长度上限 |
| `longTermEnabled` | `true` | 关掉就只保留最近对话 |
| `emotionDecayHalfLifeHours` | `18` | 心情回归基线的时间常数（小时） |
| `freezeEmotionPerMessage` | `true` | 单条消息不重复推进情绪衰减 |

### emotion — 情绪

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `textEnabled` / `audioEnabled` / `videoEnabled` | `true` / `true` / `false` | 三路开关 |
| `weights` | `{text:0.5, audio:0.3, video:0.2}` | 融合权重 |
| `moodInertia` | `0.72` | 心情惯性，越大越不容易被单句话带跑 |
| `affinityGainPerTurn` | `0.35` | 每次互动涨多少亲密度 |
| `videoSampleMs` | `4000` | 每多少毫秒取一次面部表情 |

### voice — 语音

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `autoSpeak` | `true` | 回复时自动读出来 |
| `asr.backend` | `whisper` | 识别后端 |
| `asr.language` | `zh` | 识别语言 |
| `asr.threads` | `4` | CPU 线程 |
| `asr.model` | `base` | 模型规格：`tiny` / `base` / `small` / `medium` |
| `asr.binPath` | 空 | 自定义 whisper-cli 路径（留空自动找） |
| `tts.backend` | `sapi` | `sapi` / `openai`（本地 TTS 服务）/ `off` |
| `tts.sapiVoice` | 空 | 指定音色，留空自动挑中文音色 |
| `tts.rate` / `tts.volume` | `0` / `100` | 语速、音量 |
| `tts.baseUrl` / `apiKey` / `model` | 空 | `openai` 后端才用 |
| `wake.enabled` | `false` | 是否开启语音监听 |
| `wake.requireName` | `true` | 每次都要叫名字；关掉后活跃窗口内随便说 |
| `wake.cooldownMs` | `2500` | 两次唤醒之间的冷却 |
| `vad.*` | 见文件 | 断句参数：静音阈值、最短语音、停顿多久算说完 |

### console — 管理页

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `port` | `8799` | 端口，被占用会往后试，最多 12 次 |
| `lanAccess` | `false` | 打开后绑 `0.0.0.0`，同局域网的其他设备也能开管理页 |
| `openOnStart` | `false` | 启动时自动打开管理页 |

> `lanAccess` 打开意味着同网络的人都能读到你的聊天记录和记忆，也会看到配置页。**除非你清楚在做什么，否则不要开。**

## 五、换成你自己的 Live2D 模型

1. 把 Cubism 4 模型整个文件夹丢进 `<应用目录>\resources\app\app\assets\live2d\你的模型名\`（开发模式是 `app\assets\live2d\你的模型名\`）；
2. 文件夹里要有 `<模型名>.model3.json`；
3. 重启应用，管理页 → 桌宠 → **Live2D 模型** 下拉里就会出现它。

模型目录是按「子文件夹名 = 模型 id，文件夹里有 `*.model3.json`」来找的，不需要改代码。

要重新量一遍内容范围（换了模型尺寸差很多时建议做），在桌宠窗口里按开发者快捷键重载，或者直接重启应用——每次加载都会重新测。

## 六、常见问题

**管理页打不开**
看日志里 `管理页已启动 http://127.0.0.1:xxxx` 那一行的实际端口。端口被占用会自动 +1。

**点「下载语音组件」没反应**
先看管理页 → 日志。任务进度在同一个页面的进度条上（`GET /api/runtime/progress`）。同一时间只允许一个下载任务。

**识别结果总是空**
`base` 模型对轻声和远场麦克风比较吃力。换 `small` 试试，或者把麦克风拿近一点。识别参数里的「最短语音」调低也能挽回一些短句。

**换电脑后记忆还在吗**
`%APPDATA%\小满桌宠\` 整个拷过去就行。API Key 也在里面，注意别把它传到公开地方。

**想彻底重置**
关掉应用，删掉 `%APPDATA%\小满桌宠\data\`，重启就是全新的它（模型不用重下）。
