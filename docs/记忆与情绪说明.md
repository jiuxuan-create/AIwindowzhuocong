# 记忆与情绪说明

这套东西想让桌宠表现得像「认识你」，而不是每次开场都从零开始。分两条线：**记得住**（记忆）和**读得懂**（情绪）。两条线都完全跑在本机，唯一的例外是你自己配置的对话模型。

---

## 一、记忆

### 1.1 三层结构

| 层 | 存什么 | 进不进上下文 | 存在哪 |
| --- | --- | --- | --- |
| 最近对话 | 最近 `recentTurns` 轮原始对话 | 全量进 | `conversation.jsonl` |
| 相处摘要 | 每 `summarizeEveryTurns` 轮滚动生成一段 | 只带最近一条 | `summaries.jsonl` |
| 长期记忆 | 抽取出来的事实 / 偏好 / 事件 / 关系 | 按相关度召回 6 条 | `longterm.jsonl` |

每次回复前，`app/core/context.js` 把这三层拼成一份提示词：人格设定 + 相处摘要 + 召回的长期记忆 + 最近对话 + 当前情绪线索。提示词的实际长度会写在日志里（`promptChars`）和管理页的「对话」页里。

### 1.2 长期记忆怎么来的

每轮对话结束后，抽取器从**用户说的话**里找值得长期记住的内容，异步进行，不阻塞回复。两种模式：

**有对话模型时**——交给模型做结构化抽取，要求输出严格 JSON：

```json
{"memories":[{"kind":"fact|preference|event|relation","text":"...","salience":0.0~1.0,"keywords":["..."]}]}
```

模型能读出本地规则抓不到的隐含信息，比如「最近老是加班到十一点」→「用户近期工作强度大」。

**没有 Key 时**——退回本地正则规则，覆盖这几类句式：

| 类型 | 触发的说法 |
| --- | --- |
| 偏好 | 我喜欢 / 我最爱 / 我讨厌 / 我不吃 / 我怕…… |
| 事实 | 我是…… / 我在……工作 / 我住在…… / 我养了只猫 |
| 关系 | 我老婆 / 我老板 / 我室友…… |
| 事件 | 我昨天 / 我最近 / 我刚…… |

一句话总结：**没配模型也能记住事，配了模型记得更准**。走本地规则时，记忆的 `origin` 字段是 `local-rule`，走模型是 `llm`，管理页和接口里都能看到，方便你判断它的可靠程度。

抽取失败、或模型返回的 JSON 解析不出来，会静默降级到本地规则，不会打断聊天。

### 1.3 召回是怎么打分的

中文不引分词依赖：CJK 走**字符二元组**（「不吃辣」→ 不/不吃/吃辣/辣），拉丁字母和数字走整词。打分是 BM25 乘几个系数：

```
最终分 = BM25(查询词相关度)
       × (0.55 + 0.45 × 时间衰减)    ← 45 天半衰期
       × 重要度系数(0.6 + salience × 0.8)
       × 反复召回惩罚(recallCount > 3 时降到 0.9)
```

低于 `minScore`（默认 0.1）的不进上下文，最多取 `retrievalTopK`（默认 6）条。

管理页 → 记忆 → **召回测试**：输入任何一句话，就能看到这句话会翻出哪几条记忆、各自多少分、命中了哪些词。调完参数想验证效果，先用这个，不用真的去聊天。

### 1.4 印象可以改

记忆不是黑盒，管理页里每一条都能：

- **改文字**：它记错了，直接改；
- **调重要度**：`salience` 拉高，以后更容易被想起来；
- **让它忘掉**：软删除，记录保留在文件里（带 `deleted` 标记），但不再参与召回；
- **手动添加**：比如「用户对花生过敏」这种一次说清更省事的事。

删掉的记忆在文件里留有痕迹，方便你回查「它到底是从哪句话记成这样的」。

### 1.5 相处摘要

每满 `summarizeEveryTurns` 轮（默认 10 轮）生成一条摘要，把这一段相处浓缩成一段话（上限 `maxSummaryChars`，默认 1400 字）。它的作用是：让你俩聊了很久以后，它还记得「上个月你在忙什么」这个量级的事，而不是只剩最近几句。

管理页 → 记忆 → 相处摘要里能看历史，也可以点「立刻生成」不等轮数。

## 二、情绪

### 2.1 三路信号

| 来源 | 怎么算 | 默认权重 | 开关 |
| --- | --- | --- | --- |
| 文字 | 中文情绪词典打分（否定词、程度副词都会修正） | 0.5 | `emotion.textEnabled` |
| 声音 | 音量、音高与音高变化、语速、停顿比例、有声比 | 0.3 | `emotion.audioEnabled` |
| 表情 | MediaPipe 面部 blendshape（嘴角、眉、眼、下颌） | 0.2 | `emotion.videoEnabled`，默认关 |

每路信号都带一个**置信度**：声音太短（< 250ms）或基本没声音时置信度只有 0.05，面部没什么表情时同理。融合时每路的实际权重是 `配置权重 × 置信度`，所以「没信号」的那一路不会污染结果。

融合后还会做一次惯性平滑（`moodInertia`，默认 0.72），避免情绪跟着单句话剧烈抖动。

**关于隐私**：声音特征在渲染进程里算完就只剩几个数字；摄像头画面也是本地 WASM 推理，不截图、不落盘、不出进程。关掉摄像头权限或在设置里关掉这一路，它就完全看不到你。

### 2.2 桌宠自己的状态

融合出来的「你的情绪」只影响它的判断，它还有一套自己的状态：

| 状态 | 默认 | 怎么变 |
| --- | --- | --- |
| `mood` | 效价 0.14 / 唤醒 0.34 | 每次互动向基线回归，用户情绪好它跟着上扬，被夸涨、被骂跌 |
| `userMood` | 效价 0 / 唤醒 0.32 | 对用户情绪的滑动估计，指数平滑 |
| `affinity` | 0.08 | 每轮 +`affinityGainPerTurn`/100（默认每轮 +0.0035），上限 1 |
| `energy` | 0.85 | 连续互动时下降，空闲时恢复；低于 0.18 会显示疲惫 |
| `interactions` | 0 | 累计互动次数 |

心情随时间向基线回归，半衰期由 `emotionDecayHalfLifeHours` 控制（默认 18 小时）。意思是：你下班回来，它不会还停在早上那个情绪上。

> 这里有过一个真实的坑：唤醒度的更新最初写成「每次互动固定 +0.2」，配上 0.82 的衰减系数，数学上的不动点是 1.11——也就是说不管你说什么，聊几句之后它的唤醒度就会永久钉死在 1.0，永远一副受惊的样子。现在改成向一个目标值松弛（默认 0.46，被夸或被骂时临时抬高），情绪才真的能随对话起伏。

### 2.3 状态怎么变成表情

心情 + 精力映射到 Live2D 表现（`toExpression`）：

| 条件 | 表现 | Haru 模型上 |
| --- | --- | --- |
| 精力 < 0.18 | `tired` | F04 + 眼开度压到 0.35 |
| 效价 ≥ 0.3 且唤醒 ≥ 0.68 | `excited` | F05 笑眯眼 |
| 效价 ≥ 0.3 且唤醒 ≤ 0.3 | `content` | F01 微笑 |
| 效价 ≥ 0.3 | `happy` | F01 |
| 效价 ≤ -0.3 且唤醒 ≥ 0.68 | `angry` | F03 |
| 效价 ≤ -0.3 且唤醒 ≤ 0.3 | `sad` | F08 |
| 效价 ≤ -0.3 | `anxious` | F04 |
| 唤醒 ≥ 0.74 | `surprised` | F06 |
| 唤醒 ≤ 0.22 | `tired` | F04 |
| 其余 | `calm` | 不套表情，保持呼吸与眨眼 |

### 2.4 情绪曲线

每次互动都会往 `emotion.jsonl` 写一条样本，管理页 → 情绪 里画最近 72 小时的四条线：你的效价、你的唤醒、它的心情、亲密度。

曲线是用 Canvas 直接画的，没有任何图表库依赖。样本点少于 2 个时会提示「还没有足够的数据」。

## 三、这套设计里踩过的坑

记下来，免得以后改回去：

1. **唤醒度固定加成** → 情绪饱和，见 2.2 的说明。
2. **召回分数没有时间维度** → 三个月前一句随口说的话会挤掉昨天刚发生的事。现在时间衰减只占 45% 的权重，短期重要事件也能靠 `salience` 顶上来。
3. **单条消息就推进情绪衰减** → 连着发五条短消息，心情会被反复冲刷。`freezeEmotionPerMessage` 就是为此加的。
4. **摘要只保留最新一条** → 只带最近一条摘要是有意为之：更早的内容应该已经被沉淀成长期记忆了。如果你发现它在忘事，先去看长期记忆里有没有对应条目，再考虑调大 `retrievalTopK`。

## 四、想调效果，从哪儿下手

| 现象 | 先改什么 |
| --- | --- |
| 它记不住重要的事 | 检查「记忆」页里有没有那条；没有的话把 `summarizeEveryTurns` 调小，或手动加一条 |
| 它老是想起不相关的事 | 把 `minScore` 从 0.1 提到 0.2 左右 |
| 它情绪太迟钝 | 把 `moodInertia` 从 0.72 降到 0.5 附近 |
| 它情绪太跳 | 反过来，把 `moodInertia` 提到 0.85 |
| 它老是显得很兴奋 | 看情绪页的唤醒值；如果长期贴 1.0，确认用的是修好之后的版本 |
| 亲密度涨太慢 | 调大 `affinityGainPerTurn` |
| 上下文太长、回复变慢 | 调小 `recentTurns`，或关掉 `longTermEnabled` 只用最近对话 |
